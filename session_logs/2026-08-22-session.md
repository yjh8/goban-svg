under a default-deny permission profile with `--ignore-user-config` and a
filtered environment. Probe-verified: `~/.ssh`, `~/.aws`, `~/.codex` denied;
toolchain works; a canary token absent from `env`. Known residual: global temp
stays readable via `:minimal`.

## Lessons recorded in build-learnings.md

1. Author CSS silently defeats `[hidden]` (author origin beats UA origin).
2. Codex reviews need a project-local, detached `CODEX_HOME`.
3. "That risk is inherent" is a claim to CHECK against current docs, not assert.
4. Every sandbox tightening needs a PROBE to find what it broke.
5. Cloudflare Pages answers ANY missing path with 200 + index.html — status
   codes cannot prove existence; check content.
6. A served-file `fetch()` probe is not evidence of what the page is RUNNING
   (stale ES module cache burned two verification attempts).
7. Don't redirect a guard script's output to /dev/null — a correct refusal
   looked like success and left a stale deploy staging.
